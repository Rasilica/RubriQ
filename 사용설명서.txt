RubriQ 사용설명서 (Windows)

■ 준비
  - Windows 10 또는 11, 인터넷 연결 (처음 실행할 때 필요한 프로그램을 내려받습니다)
  - 받은 압축 파일을 마우스 오른쪽 버튼으로 눌러 "압축 풀기"를 합니다.
    압축 파일 안에서 바로 실행하면 동작하지 않습니다.

■ 실행
  1. 압축을 푼 폴더에서 "RubriQ실행.bat"을 두 번 클릭합니다.
     "Windows의 PC 보호" 창이 나오면 "추가 정보" → "실행"을 누릅니다.
  2. 처음에는 몇 분 걸릴 수 있습니다. 검은 창을 닫지 마세요.
  3. 번호를 입력하고 Enter를 누릅니다.
       1 = 체험 모드 (추천)
       2 = 실전 모드
  4. 브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 입력합니다.
       http://127.0.0.1:8293/prepare
  5. 끝낼 때는 검은 창을 닫습니다.

■ 체험 모드 순서 (API 키와 비용 없음)
  1. 문서 올리기: 프로젝트명을 입력하고 samples 폴더 안의 pdf 폴더에서
       안내문: guide.pdf
       보고서: missing.pdf (normal.pdf, paraphrased.pdf도 가능)
     를 골라 "문서 준비하기"를 누릅니다.
  2. 읽은 내용 확인: 원문과 PDF를 확인한 뒤 "다음"을 누릅니다.
  3. 요구사항 뽑기: "안내문에서 AI로 보낼 내용 미리보기" → 확인란 체크
     → "동의한 범위로 AI 실행"
  4. 요구사항 확정: 4번 항목의 "조건 적용 여부"를 "적용하지 않음"으로 고르고
     사유를 입력한 뒤 "수정한 요구사항 확인·확정"을 누릅니다.
  5. 보고서 검사: "보고서 검사에 보낼 내용 미리보기" → 확인란 체크 → 실행
  6. 결과·보관: 항목별 판단과 근거를 확인합니다. "문서 보관하기"로 저장할 수 있습니다.

  체험 모드의 결과는 미리 저장한 예시이며 실제 AI가 검사한 것이 아닙니다.
  4번 항목을 "적용"으로 고르면 저장된 예시가 없어 "판정 보류"로 표시됩니다.

■ 실전 모드
  - 화면의 "AI API 키 설정"에서 본인의 API 키(Gemini, OpenAI, Anthropic, 빌링AI)를
    입력하거나, 설치된 Ollama를 사용합니다.
  - AI를 실행하면 화면에 표시한 문서 내용이 선택한 업체로 전송되며 비용이 발생할 수
    있습니다. (Ollama는 내 컴퓨터에서 처리합니다)
  - PDF, DOCX, HWPX를 올릴 수 있습니다. HWP는 Windows에서 지원하지 않습니다.
    DOCX와 HWPX는 글 내용은 읽지만 PDF 미리보기는 표시되지 않습니다.

■ 문제가 생기면
  - "이미 실행 중" 메시지: 열려 있는 검은 창을 모두 닫고 다시 실행합니다.
  - 설치 실패: 인터넷 연결을 확인하고 다시 두 번 클릭합니다.
  - 폴더 경로가 너무 길면 C:\RubriQ 처럼 짧은 위치에 풀어 주세요.
